# Tiny WebXR Room

A tiny WebXR demo for HTTPS hosting such as GitHub Pages.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select your main branch and `/ (root)`.
5. Open the HTTPS Pages URL on your phone.
6. Tap **ENTER VR**.

Controls:
- Look around: headset/phone head tracking through WebXR
- Walk: WASD or arrow keys when available

The demo uses Three.js from jsDelivr, so the page needs internet access.
